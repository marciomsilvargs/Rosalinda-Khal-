# Rosalinda Khal e João Luiz Filho — Advocacia

Landing page institucional para o escritório de advocacia **Rosalinda Khal e João Luiz Filho — Advocacia**, localizado em Alvorada, RS.

## ⚖️ Sobre o Projeto

Website desenvolvido com foco em alta performance, elegância visual e experiência responsiva em todos os dispositivos (desktop, tablet e mobile). Apresenta as áreas de atuação jurídica, perfil dos advogados sócios e canais diretos de contato e atendimento via WhatsApp.

### Áreas de Atuação
- Direito de Família e Sucessões
- Direito Previdenciário (INSS)
- Direito do Trabalho
- Direito Civil e do Consumidor
- Direito Imobiliário

## 🚀 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado.

### Execução
Inicie o servidor estático local nativo:

```bash
node server.mjs
```

O servidor iniciará em `http://localhost:8080` e abrirá a página automaticamente no seu navegador padrão.
